Import TI-84 Plus CE .8xl list files, TI-84 Evo .8xl2 list files, get lists from a connected Evo or Plus CE, edit list values, then export any column—or all columns—to either format or send one list or all lists to a connected Evo or Plus CE.

Ready. Load up to 12 list files. Lists 1–6 are shown by default.
Numeric cells accept ordinary decimal notation or scientific notation such as 1.25e-6. CE real values use the calculator's 14-digit BCD representation. Evo files use the TI-84 Evo CBOR container and numeric-expression layout. Plus CE WebUSB supports importing and sending lists, with confirmation before replacing populated calculator lists. Evo WebUSB supports importing and sending standard L1–L6 lists; the WebUSB import button automatically primes the Evo CDC port via Web Serial once per page session before reading data. Chrome may request Web Serial and WebUSB access separately the first time. The editor shows six lists by default and expands automatically when additional list slots are needed. All processing stays in this browser tab.
